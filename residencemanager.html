Residence Manager

Residence Manager — это единая экосистема управления доступом и оплатой в жилом комплексе, состоящая из трёх взаимосвязанных модулей, привязанных к общей биллинговой платформе. Лифтовая система разработана с нуля с собственным софтом для микроконтроллера и оригинальным дизайном печатной платы: картридер в кабине считывает защищённую NFC-карту жильца с шифрованием, открывая доступ только к заданному этажу с невозможностью клонирования благодаря современным алгоритмам защиты. Нативное мобильное приложение для iOS и Android с полной кастомизацией дизайна позволяет активировать гостевой доступ через считывание NFC-карты смартфоном, автоматически открывая нужный этаж в течение минуты. Домофонная панель у входа включает планшет с перечнем квартир и встроенный картридер: гость выбирает квартиру, звонок поступает владельцу в приложение с двухсторонней видеосвязью высокого качества и возможностью открыть дверь одним касанием даже вне дома.

Шлагбаумы и ворота управляются через мобильное приложение или автоматически распознают номера машин через OCR-камеры с высокой точностью в любых погодных условиях. Единая биллинговая подсистема учитывает использование всех сервисов — лифта, домофона и парковки, поддерживая различные тарифные планы и льготы для разных категорий жильцов с автоматической блокировкой доступа при задолженности по коммунальным платежам до погашения долга. Residence Manager создает комфортную и безопасную среду проживания с полной автоматизацией управления жилым комплексом.
